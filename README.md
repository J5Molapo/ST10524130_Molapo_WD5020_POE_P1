# Trailblazer Esports Arena — Website Redesign

A modern, responsive website for **Trailblazer Esports Arena**, showcasing membership tiers, training services, merch, and contact/enquiry forms.

## Project Details

- **Client:** Trailblazer Esports Arena (Owner: Jeffery Yelnats)
- **Developer:** Napo Molapo
- **Date:** August 2026
- **Purpose:** Website Redesign & Development (WIL practical module)

## Goals

- Improve user experience and navigation across devices.
- Enable online membership sign-ups and easier e-commerce.
- Build brand identity and visual hierarchy to attract and retain customers.

## Features

### Pages

1. **Index.html** — Home page with welcome and quick links to offerings.
2. **About.html** — Mission, overview, goals, and team information.
3. **Products.html** — Membership tiers, training services, and merchandise display.
4. **Enquiry.html** — Enquiry form with name, email, phone, subject, and message fields.
5. **Contact.html** — Contact details (phone, email, address, business hours).

### Membership Tiers

- **Day Pass:** $15/day
- **Silver:** $49/month
- **Gold:** $99/month
- **Platinum:** $199/month (includes merch and tournament endorsement pathway)

### Training & Services

- **1-on-1 Coaching:** $35/hr
- **Team Bootcamps:** $250/week
- **Seminars:** Schedule available on events

### Merchandise

- Hoodies
- T-shirts
- Controller Packs

## Technical Stack

- **Frontend:** HTML5, simple semantic markup
- **Images:** TrailBlazer logo and product images (Images_Resources folder)
- **Forms:** Functional enquiry form with client-side validation and confirmation

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/J5Molapo/ST10524130_Molapo_WD5020_POE_P1.git
   cd ST10524130_Molapo_WD5020_POE_P1
   ```

2. Open any `.html` file in your browser to view the website.

3. Navigate between pages using the header navigation links.

4. Fill out the Enquiry form (currently shows a confirmation message on submit).
