## Project Overview
Trailblazer Esports Arena is a gaming and esports venue that provides arena access, memberships, training services, and community-focused engagement. This project involved designing and building a responsive website that presents the brand clearly, communicates its offerings, and creates a professional online presence for the business.

## Website Goals and Objectives
- Create a modern, user-friendly website for Trailblazer Esports Arena.
- Showcase membership options, coaching services, and arena experiences clearly.
- Improve online visibility and brand identity for the business.
- Provide an easy path for users to explore services and make enquiries.
- Ensure the website is responsive and easy to navigate on different devices.

## Key Features and Functionality
- Homepage with welcoming branding and platform overview
- About page with business background and company information
- Products page showing membership packages and service offerings
- Contact page with business contact details and location information
- Enquiry form for visitor communication
- Responsive layout for desktop, tablet, and mobile compatibility
- Simple and clear navigation structure across pages
- Visual imagery to support the esports brand and atmosphere

## How to View the Site Locally
1. Open the project folder in VS Code.
2. Run the **Start Website** task from **Terminal > Run Task**. It uses Windows PowerShell, so Python and Node.js are not required.
3. Open `http://localhost:8000/Index.html` in a browser.
4. Stop the server with Ctrl+C in the task terminal when finished.

You can also start the server from PowerShell in the project folder with `./Start-Website.ps1`.
